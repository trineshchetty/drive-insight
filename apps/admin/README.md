# Drive Insight - Admin Application

Platform administration dashboard for managing tenants, monitoring, and cross-tenant analytics.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript (strict mode)
- **Styling:** Tailwind CSS 4.x
- **Branding:** Purple theme (differentiated from tenant dashboard)

## Development

```bash
# Install dependencies (from project root)
pnpm install

# Run dev server (port 3002)
pnpm dev

# Build for production
pnpm build
```

- Tenant onboarding & management
- Cross-tenant analytics
