THE SOLUTION

Tool-Boundary Controls

Stop trying to filter the input.
Start constraining the output.

Enforce Schemas

Force the LLM to output strict JSON schemas. Reject anything that doesn't match the type definition.

Least-Privilege

Give the agent its own identity. Never let it run as root or inherit user permissions blindly.

Deterministic Gates

Use traditional code (not AI) to validate actions before execution. Human-in-the-loop for high stakes.

Core Principle: Treat the LLM as an untrusted component
