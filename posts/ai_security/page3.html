To the LLM, these are all just "tokens" with equal authority

LLMs cannot separate instructions from data. Unlike SQL databases, there is no structural wall between code and user input.

To the model, there are no "commands"—only the next token in the sequence.

This makes any text-based filtering inherently probabilistic and easily confused by crafted inputs.
